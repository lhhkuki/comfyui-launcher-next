# 产品完善计划

目标：让 Comfy Station 成为可信、低噪音的 ComfyUI 环境管理工作台，而不是重复实现节点编辑器。

## 本轮交付

- [x] 统一页面标题、搜索、工具栏和焦点样式。
- [x] 增加任务中心：并发计数、成功/失败结果、环境标识、本地历史和中断状态。
- [x] 工作流检查增加模型引用候选和本地匹配；明确区分缺失与无法确认。
- [x] 连接工作流分析、插件处理、模型查找、模式生成和运行中心。
- [x] 验证类型、构建、回归、多尺寸布局和便携 EXE。

## 后续阶段

1. 后端任务生命周期：有明确进度的下载/安装任务，只有可安全取消的操作提供取消；不要假装取消已终止子进程。
2. 安全更新闭环：版本记录、备份清单、失败恢复入口、恢复结果验证。
3. 输出关联：读取文件中实际存在的工作流元数据，关联生成环境并支持收藏、批量整理。
4. 真实环境回归：不同 Python、模型引用、Windows 缩放、多实例和损坏配置。

## 边界

静态工作流分析不是运行验证。普通前端 JSON 的 widgets_values 没有统一字段语义，模型文件名只能作为候选；不能自动下载或安装。未知节点不能直接认定缺失。任务历史仅保存本地摘要，不保存完整命令输出。第一轮不实现依赖的自动取消或自动修复。
